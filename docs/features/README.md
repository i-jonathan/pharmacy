# Feature docs

Each feature has a staff guide (for owners, managers and cashiers) and a technical doc (for developers and AI agents). Templates are in [templates/](./templates/). Docs are written and refreshed with the `document-feature` skill.

| Feature | Staff guide | Technical | What it does |
|---|---|---|---|
| Customers | [guide](./customers/guide.md) | [technical](./customers/technical.md) | Keep a list of customers with phone, email, notes and consent to be contacted |
| Purchase orders | [guide](./purchase-orders/guide.md) | [technical](./purchase-orders/technical.md) | Plan reorders, get them approved, send to suppliers and receive against them |
